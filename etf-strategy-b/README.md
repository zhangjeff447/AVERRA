# ETF Strategy B v2.0 · 无 TQQQ

状态截至 2026-11-12 为 **待盘中只读验收与正式切换**。公开目录含候选策略和离线回测入口。执行集成源码位于 `integration/`，依赖既有执行服务，未随公开目录打包运行配置或部署流程。

VOO 和 SMH 只买不卖。长期战略基准按两只 ETF 的合计市值计算，VOO 20%、SMH 80%。VOO 低于 15% 或 SMH 低于 70% 时，优先用现金向长期基准纠偏。资金限于券商核实的已结算可用自有现金。TQQQ 无下单权限，QQQ 用于市场信号。

| 状态 | 当期现金分配 VOO／SMH |
| --- | --- |
| 防御 | 80%／20% |
| 恢复 | 50%／50% |
| 进攻 | 30%／70% |
| 强牛 | 10%／90% |

市场状态使用 QQQ 已完成的复权日线、MA50、MA200、20 日收益和 20 日年化波动率。普通状态连续确认 3 日，强牛 5 日。既有生产调度为 10:05、12:30、15:30 ET。若当天已确定分配，之后到账的额外资金进入下一交易日的计划。

## 历史回测

每组从 $10,000 起步，之后每月首个交易日入金 $400，使用前收盘信号和次日开盘价模拟，单边滑点 5 bps。

| 区间 | 现版期末 | Strategy B 期末 | 最大回撤 现版／Strategy B |
| --- | ---: | ---: | ---: |
| 2013-01-02 至 2026-11-11 | $656,628 | $771,312 | 36.57%／41.10% |
| 2021-01-04 至 2026-10-01 | $127,092 | $129,507 | 39.34%／39.60% |

两段样本的期末价值和最大回撤都更高。模拟只使用开盘价，实盘窗口的成交差异未纳入。

## 本地运行

使用 Python 3.11 或更新版本。准备按 NYSE 交易日对齐的 `VOO.csv`、`SMH.csv`、`TQQQ.csv`、`QQQ.csv`，每份含 `Date, Open, Close, Adj Close, Dividends, Stock Splits`。另备 `DGS3MO.csv`，第一列为日期，数据列为 `DGS3MO`。TQQQ 文件用于兼容共享行情格式。起始日前需留至少 200 个交易日的预热数据。

```sh
python -m pip install -r requirements.txt
python replay.py --data ./market-data
```
